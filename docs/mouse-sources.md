## 数据边界

- M650为标准右手版本；Lift为右手版本，不能用其他左手版本参数替代。M350s/G304的左右手适用性在本次未核实，左手硬条件下会保守排除。
- M240消费版为Bluetooth；不能套用M240 for Business的接收器资料。M350s接收器支持/随盒情况未在本次核实，保留未知。
- 官网M331页面部分功能段落使用M330字样；保留原来源，不将该命名混用解释为另一款产品。
- G304香港官网文本及图库使用G305命名；本库依据官方G304页面及G304支持规格，图片为该官方页提供的图库图片。
- 静音只有官网/页面有明确依据时记录为true；未知不是false。重量仅M350s（76g）、M650（101.4g）及G304（99g）在本次核实；其他保留null。M350s重量来自所列零售商详情。
- 未逐项核实最低OS版本、所有设备系统兼容性或实际游戏延迟，因此未宣称已满足这些条件。未实现系统版本过滤。蓝牙是否可用和USB-A是否可用为独立字段，不从USB-C-only假设蓝牙。
- 不把厂商推荐手型/重量等同个人舒适度。供电、尺寸、续航无法可靠提取的字段明确显示未核实。
- 鼠标图片本地保存于public/images/，HTTP白名单逐款提供；来源链接保留。图片版权归Logitech，不代表取得开源图片授权。为本地课程原型展示引用，公开传播前应核对使用许可。8张PNG已验证文件头与HTTP返回，浏览器实际显示验证了M240、M350s、M650三款。
